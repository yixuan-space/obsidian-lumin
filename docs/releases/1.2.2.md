# Lumin 1.2.2

## 设置页标题栏

- 设置子页面（字体、快捷键等）的吸顶标题栏改为与内容区一致的实色背景，向上滚动时列表条目不再从标题栏下透出。
- 标题栏下方的渐变遮罩换成同样的实色，滚动内容的边缘过渡保持不变。
- 半透明窗口模式下标题栏跟随该模式的纯色内容面，不会出现色带。

## Mermaid、关系图谱与 Canvas

- Mermaid 图表按笔记配色重新着色：节点、边框、连线、标签与集群底纹全部取自当前调色板，浅色与深色模式一致。
- 深色模式移除 Obsidian 对 Mermaid 的反色滤镜，改由主题直接使用深色配色，避免颜色被二次反转。
- 过宽的 Mermaid 图会在窄面板与手机上自适应缩放，不再横向溢出。
- 关系图谱的节点、连线与文字跟随强调色和正文色；图谱控制面板改为与菜单一致的半透明浮层。
- Canvas 的画布底色比笔记低一档，卡片标签使用次要文字色，胶片色与点阵背景随明暗模式调整。

## 侧边栏

- 左侧边栏的最小宽度在工具栏宽度基础上再增加 8px，拖动分隔条时面板内的按钮仍保持完整间距。
- 侧边栏拖拽手柄从原生 3px 加宽到 8px，左右两侧都更容易被抓住；悬停时只显示细分隔线，不再出现整块高亮。
- 悬停显示功能区改为带圆角与阴影的卡片浮层：鼠标靠近窗口左侧任意高度都能唤出，功能区内容较长时可在浮层内滚动。
- 启用「侧边栏控件常显」后，文件浏览器的操作按钮与标签保持完整显示，不再被收起成细条。

## 配色与可读性

- 深色模式的链接颜色提亮为 `#6ea8e8`，在深色正文上的对比更清晰。
- 浅色模式的次要文字色加深为 `#6f6f6f`，暖灰配色同步调整为 `#6b6964`，设置项描述等辅助文字的辨识度提高。

## 设置面板

- 重写了 Style Settings 中全部设置项的中英文说明，改为描述实际生效的行为。
- 移除「取消紧凑面板操作区」，相关行为并入「侧边栏控件常显」。
- 新增「常驻状态栏」与「桌面端图标尺寸」两个设置项。
- 移动端的「关闭模式切换浮钮」与「动态界面字号」移入单独的移动端分组，桌面端不再显示。

## 验证与安装

- 使用独立临时配置的 Microsoft Edge 检查脚本验证主题排版、代码对比度、配色方案、侧边栏布局、Mermaid、图谱与 Canvas，并新增设置页标题栏不透明度的回归检查。
- 下载 `manifest.json` 和 `theme.css`，放入笔记库的 `.obsidian/themes/Lumin/`。
- 最低 Obsidian 版本仍为 **1.11.6**。
- `typora-hotkeys.zip` 为可选的独立快捷键工具，本次未修改工具功能。

## English

The sticky titlebar on settings sub-pages (fonts, hotkeys and so on) now paints the same opaque surface as the content area, so list rows no longer bleed through while scrolling. The gradient mask below the titlebar uses that same solid colour, keeping the existing fade at the content edge, and translucent windows fall back to their solid content surface.

Mermaid diagrams are re-coloured from the note palette: nodes, borders, edges, labels and cluster fills follow the active scheme in both light and dark mode. Dark mode drops Obsidian's inverting SVG filter and paints the diagram from the theme's own dark palette instead. Wide diagrams now scale down inside narrow panes and phones. Graph view nodes, links and labels follow the accent and text colours, and its controls use the same translucent overlay as menus. Canvas sits one step behind notes, with muted card labels and dot patterns that follow the current mode.

The left sidebar's minimum width grows by another 8px beyond its toolbar, so panel actions keep their spacing while the split is dragged narrow. The resize handle is widened from the native 3px to 8px on both docks and shows only a hairline while hovered. The hover ribbon is now a rounded card with a shadow that can be revealed from any point along the left window edge and scrolls when its actions overflow. With "Always show sidebar controls" enabled, file explorer actions and tabs stay fully visible.

Dark-mode links brighten to `#6ea8e8`, and light-mode secondary text darkens to `#6f6f6f` (`#6b6964` in the warm gray scheme) for clearer descriptions and labels.

Every Style Settings entry has rewritten Chinese and English descriptions that describe the behaviour they actually toggle. "Disable compact panel actions" was removed in favour of "Always show sidebar controls", "Always-visible status bar" and "Desktop icon size" were added, and the mobile-only mode switch and dynamic type settings moved into their own mobile group.

Checks used the isolated Microsoft Edge harness for typography, code contrast, palettes, sidebar layout, Mermaid, graph view and Canvas, with a new regression check that keeps the settings titlebar opaque. Install `manifest.json` and `theme.css`; minimum Obsidian version remains **1.11.6**. The optional portable hotkey tool is unchanged.
