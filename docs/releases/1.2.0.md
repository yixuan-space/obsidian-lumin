# Lumin 1.2.0

## 阅读／编辑切换

- 阅读与编辑模式的切换按钮改用借鉴自 Velocity 主题的图标：阅读为眼镜，编辑为钢笔。
- 按钮保留 Obsidian 原生的操作按钮尺寸和圆角，鼠标悬停时的高亮范围与右侧相邻图标一致。
- 图标与右侧图标等大，并在两者之间保留少量间距。
- 移除了编辑模式下把切换按钮填充为主题蓝的规则，避免与新的图标样式冲突。
- 阅读状态下图标使用次要文字色，编辑状态下使用正文颜色。

## 左下角工作区切换

- 左下角的笔记库切换行改为常显的圆角条目，样式借鉴自 Velocity，鼠标悬停时显示高亮背景。
- 笔记库图标换成描边更粗的水晶线框图标，文字仍沿用 Lumin 的字体与排版。
- 该行不再以浮层方式覆盖文件列表，也不再需要悬停才展开，文件列表底部保留完整可视区域。

## 验证与安装

- 使用独立临时配置的 Microsoft Edge 内置浏览器检查脚本，以及本机 Obsidian 窗口截图核对图标尺寸、间距和悬停效果。
- 下载 `manifest.json` 和 `theme.css`，放入笔记库的 `.obsidian/themes/Lumin/`。
- 最低 Obsidian 版本仍为 **1.11.6**。
- `typora-hotkeys.zip` 为可选的独立快捷键工具，本次未修改工具功能。

## English

The reading/editing toggle now uses icons borrowed from the Velocity theme: glasses for reading and a pen for editing. The button keeps Obsidian's native action-button box and radius, so its hover highlight matches the neighbouring header icons, and it sits at the same icon size with a small gap before them. The edit-mode accent fill was removed so it no longer fights the new glyph, and the icon is muted in reading view and normal text colour while editing.

The vault switcher at the bottom of the left sidebar is now an always-visible rounded row inspired by Velocity, with a hover background and a heavier wireframe vault icon while keeping Lumin's own typography. It no longer floats over the file list or expands only on hover, so the file list keeps its full visible area.

Checks used the isolated Microsoft Edge harness plus native Obsidian window screenshots for icon size, spacing and hover parity. Install `manifest.json` and `theme.css`; minimum Obsidian version remains **1.11.6**. The optional portable hotkey tool is unchanged.
