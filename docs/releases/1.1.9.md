# Lumin 1.1.9

## 编辑与阅读排版

- 优化实时预览与阅读模式的段落、空行和标题间距，减少切换模式时的布局差异，接近 Typora 的紧凑排版。
- 正文保留 1.6 倍行高；实时预览中的普通空行改为 0.8 倍行高，与阅读模式的段落间距一致。
- 标题前后留白按正文字号统一，避免标题字号放大间距，以及源文件空行与标题留白叠加。
- 空行仍可点击和输入；输入文字后恢复正常行高，光标进入空行时不改变其高度。
- 保留代码块、列表、引用内部空行及纯源码模式的原有处理，不修改笔记内容或空格。
- 连续多个空行在编辑模式仍逐行保留；阅读模式按 Markdown 规则合并，这类内容仍可能有间距差异。

## 验证与安装

- 使用独立临时配置的 Microsoft Edge，检查 16px、20px 字号及窄屏、宽屏下的正文行高、段落与标题间距、自动换行和空行输入。
- 保留原有侧栏布局与展开／收起点击检查。浏览器检查不等同于 Obsidian 原生窗口实机验证。
- 下载 `manifest.json` 和 `theme.css`，放入笔记库的 `.obsidian/themes/Lumin/`。
- 最低 Obsidian 版本仍为 **1.11.6**。
- `typora-hotkeys.zip` 为可选的独立快捷键工具，本次未修改工具功能。

## English

Brings Live Preview and Reading view closer to Typora-style spacing. Body text keeps a 1.6 line height, while ordinary empty Live Preview lines use 0.8 to match paragraph gaps. Heading spacing now uses the body font size and avoids stacking extra padding on source blank lines.

Empty lines remain clickable and editable, and regain normal height when text is entered. Code, list and quote lines, source mode, and literal note contents are preserved. Multiple source blank lines still remain individually visible in editing, whereas Markdown collapses them in Reading view.

Edge checks cover 16px and 20px text, narrow and wide viewports, wrapped paragraphs, heading gaps, empty-line input, and existing sidebar interactions. Native Obsidian window verification is separate. Install `manifest.json` and `theme.css`; minimum Obsidian version remains **1.11.6**. The optional portable hotkey tool is unchanged.
