# Lumin 1.1.8

## 笔记排版

- 参考 Typora GitHub 主题调整正文、标题层级、引用与分隔线。
- 代码采用中性灰背景、8px 圆角与更清晰的语法配色，改善注释可读性。
- 表格增加小圆角，整理网格线、表头悬停与编辑时的样式。
- 优化有序、无序及混合嵌套列表的缩进、间距和标记颜色。
- 调整高亮文字、键盘按键与脚注返回链接。
- 侧栏折叠按钮恢复 Obsidian 原生位置与点击逻辑，移除 Windows 跨区域固定定位，并明确排除按钮的窗口拖拽区域。
- Windows 顶部折叠图标与下方功能图标水平居中，并与右侧文件图标保持同一高度。
- 保留 macOS 原生按钮换位逻辑；通过 Edge 布局与点击检查，macOS 真机验证尚未完成。

## 独立快捷键工具

- 新增 Typora 风格快捷键配置，可在 Windows、macOS 和 Linux 的 Obsidian 中导入。
- Windows 双击 `Start.cmd`；Mac 双击 `Start.command`。
- 支持笔记库选择、预览、冲突检测、自动备份与恢复。
- 修复 macOS 符号链接路径下的启动判断。
- 通过同步 `.obsidian/hotkeys.json` 在同一笔记库的多台设备复用。

工具需要 Node.js 22 或更新的 LTS 版本，无需 npm 依赖或社区插件。下载 `typora-hotkeys.zip` 后解压，打开 `tools/typora-hotkeys`，保留整个文件夹。Mac 若缺少执行权限，请按工具 README 的说明为 `Start.command` 添加执行权限。导入前请完全退出 Obsidian。

## 安装与兼容性

- 主题更新：下载 `manifest.json` 与 `theme.css`，放入笔记库的 `.obsidian/themes/Lumin/`。
- 最低 Obsidian 版本仍为 **1.11.6**。
- 主题安装不会自动修改快捷键；快捷键工具需独立运行。
- 更新中英文 README，添加 Windows、Linux、macOS CI 与本机 Edge 验证工具。

## English

Typora-inspired note typography, more readable syntax colors, neutral code backgrounds, rounded code blocks and tables, improved list spacing, and simpler quote/highlight treatments. Includes a separate portable hotkey importer with Windows and macOS launchers, previews, backups, conflict detection, restoration, and multi-device guidance. Fixes launcher entry detection for symlinked macOS paths.

Restores native sidebar toggle placement and click handling, excludes its hit target from window dragging, and aligns the Windows toggle with both the Ribbon actions and the file tab icon. Preserves native macOS reparenting behavior; Edge layout/click checks passed, while native macOS verification remains pending.

Install the theme with `manifest.json` and `theme.css`. For the optional hotkey tool, extract `typora-hotkeys.zip`, open `tools/typora-hotkeys`, and keep the folder together. Node.js 22 or newer LTS is required. Minimum Obsidian version remains **1.11.6**.
