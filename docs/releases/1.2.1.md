# Lumin 1.2.1

## 侧边栏最小宽度

- 左侧边栏的最小宽度从 220px 调整为 236px，与展开后的面板工具栏等宽。
- 拖动分隔条缩窄侧边栏时，文件浏览器顶部的操作按钮保持原有间距，不再被挤出侧边栏或相互重叠。
- 最小宽度按工具栏的实际尺寸计算（`--tab-action-width` 的 5 个按钮加内边距），修改按钮尺寸时仍会保持对齐。
- 侧边栏的展开与收起行为不变，收起状态下不受最小宽度限制。

## 验证与安装

- 使用独立临时配置的 Microsoft Edge 内置浏览器检查脚本验证布局；请求 180–235px 宽度时，侧边栏均被限制为 236px，展开后的工具栏完整可见。
- 下载 `manifest.json` 和 `theme.css`，放入笔记库的 `.obsidian/themes/Lumin/`。
- 最低 Obsidian 版本仍为 **1.11.6**。
- `typora-hotkeys.zip` 为可选的独立快捷键工具，本次未修改工具功能。

## English

The left sidebar now stops shrinking at 236px — the width of its expanded panel toolbar — instead of 220px. When the split is dragged narrow, the file explorer header actions keep their spacing instead of being squeezed out of the dock or overlapping. The limit is derived from the actual toolbar size (five `--tab-action-width` buttons plus their insets), so it stays aligned if the action size changes. Collapsing and revealing the sidebar are unchanged, and the collapsed state is not affected by the minimum width.

Layout checks used the isolated Microsoft Edge harness: requests between 180px and 235px are clamped to 236px and the expanded toolbar remains fully visible. Install `manifest.json` and `theme.css`; minimum Obsidian version remains **1.11.6**. The optional portable hotkey tool is unchanged.
